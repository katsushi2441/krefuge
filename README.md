# Kurage 避難所マップ (krefuge)

住所を入れると、最寄りの**指定緊急避難場所**まで道路をたどって**徒歩何分**かを返します。
指定緊急避難場所は災害種別ごとに指定されているため、**「その災害で使える避難所」**に絞り込めます。

- デモ: https://kurage.exbridge.jp/krefuge.php/
- 収録: 全国 115,447 件 / 47都道府県
- 出典: 国土地理院「指定緊急避難場所データ」(CC BY 4.0)

## 設計の芯

### 1. 「近い避難所」ではなく「その災害で使える避難所」を出す

指定緊急避難場所は災害種別ごとに指定されます。**地震で使える場所が洪水では使えないことがあります。**
崖のそばの広場は地震では安全でも、土砂災害では危険です。
単に最寄りを返すと、その災害では使えない場所へ誘導しかねません。

| 災害種別 | 収録件数 |
| --- | --- |
| 地震 | 88,177 |
| 洪水 | 71,783 |
| 崖崩れ・土石流・地すべり | 67,289 |
| 大規模な火事 | 43,105 |
| 津波 | 40,393 |
| 内水氾濫 | 38,621 |
| 高潮 | 25,157 |
| 火山現象 | 10,723 |

### 2. 判定には必ずデータ時点を添える

このデータは**市町村ごとに更新時期が違います**。市町村別の公開日・最終更新日(1,747件)を
`muni_vintage` 表に持ち、判定結果にその市町村の時点を併記します。
**時点が確認できないデータでは判定しません。** 黙って古いデータで答えるほうが危険だからです。

### 3. 精度が落ちたことを隠さない

徒歩時間は Valhalla で道路網をたどって計算します。Valhalla が応答しない場合は
直線距離×徒歩80m/分に退避しますが、**そのことを必ず結果に明記**します(`walk_basis`)。

### 4. 「指定緊急避難場所」と「指定避難所」を混同させない

| | |
| --- | --- |
| 指定緊急避難場所 | 命を守るため**緊急的に逃げ込む場所**。災害種別ごとに指定される |
| 指定避難所 | 家に戻れない人が**一定期間滞在する施設** |

本システムが扱うのは前者です。画面と API の両方で明示します。

## なぜ PostGIS を使わないか

収録されるのは点だけで、面の包含判定が要りません。SQLite の R-tree で最近傍を引けば足ります。
Docker も PostgreSQL も不要なので、設置が簡単です。

## API

```
GET /api/check?q=<住所>&hazard=<災害種別>
GET /healthz
```

`hazard` は `landslid` `flood` `quake` `tsunami` `surge` `inlflood` `bigfire` `volcano` または省略。

## 技術メモ

- 配布 Shapefile の `.cpg` は UTF-8。`ogr2ogr -lco ENCODING=UTF-8` を付けると**二重変換で壊れる**
- 元データに 254 バイト打ち切りで日本語が途中で切れた箇所がある(2026-06-12版で実測)。
  取り込みは `errors="replace"` で読み進める。施設名・住所・災害種別フラグには影響しない
- 徒歩時間は Valhalla の `/sources_to_targets` を 1 source → N targets で 1 回呼ぶ
